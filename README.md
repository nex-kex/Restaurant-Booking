# Restaurant Booking

## Описание проекта

Проект **Restaurant Booking** — это веб-приложение для управления бронированием столиков в ресторане. Система
позволяет пользователям удобно выбирать столик, время и количество гостей, а администраторам — управлять
бронированиями и настройками ресторана (можно настроить под любой ресторан - включая время обслуживания отдельных
столиков, категории / зоны и количество столиков в них, количество мест за столиком).

### Основные возможности:

- Онлайн-бронирование столиков с выбором даты, времени и количества гостей.
- Управление доступными столиками.
- Обработка сообщений обратной связи от гостей.
- Административная панель для управления бронированиями, столиками, категориями и пользователями.
- Адаптивный интерфейс для работы с любого устройства.

## Функциональность

### Для пользователей:

- Бронирование столиков: выбор даты, времени, количества гостей и столика.
- Личный кабинет: просмотр истории бронирований и управление профилем.
- Адаптивный интерфейс: корректное отображение на мобильных устройствах и планшетах.

### Для стаффа:

- Админ-панель Django: управление бронированиями, столиками, меню и пользователями.
- Настройки: конфигурация времени работы ресторана.

## Инструкция по запуску проекта

### 1. Убедитесь, что на вашем компьютере установлены:

- Docker (версия 20.10.0 или выше)

- Docker Compose (версия 2.0.0 или выше)

Проверить установку можно командами:

```bash
docker --version
docker-compose --version
```

### 2. Клонируйте репозиторий:

```bash
git clone https://github.com/nex-kex/Restaurant-Booking.git
```

### 3. Установка

#### Установите Poetry (если не установлен)

```bash
pip install poetry
```

##### Установка зависимостей

```bash
poetry install
```

#### Настройка окружения

Создайте файл `.env` в корне проекта по примеру `.env.example`.

#### Миграции

Примените миграции

```bash
python manage.py migrate
```

### 4. Запустите проект

```bash
docker-compose up -d
```

## Проверка работоспособности

- **Бэкенд**: Откройте браузер и перейдите по адресу `http://localhost:8000`.
- **PostgreSQL**: Подключитесь к базе данных через pgAdmin или другой клиент.

#### Создание суперпользователя

Для удобного взаимодействия с [панелью администратора](http://127.0.0.1:8000/admin/) можно создать суперпользователя.

```bash
python manage.py createsuperuser
```
